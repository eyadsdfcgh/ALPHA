📜 تقرير مشروع منصة ALPHA التعليمية والتداولية
     (ALPHA Smart Money Concept Trading Platform)
================================================================================

تاريخ التقرير: 2026-10-18
اسم المشروع: ALPHA Project
الهدف: توفير منصة ويب متكاملة للمتداولين بأسلوب SMC، تجمع بين التعليم الرقمي
       المحمي وأدوات التداول المتقدمة مع نظام اشتراك احترافي متعدد الطبقات.

================================================================================
1. التقنيات المستخدمة (Technical Stack)
================================================================================
- لغة البرمجة      : Python 3
- الإطار البرمجي   : Flask (Backend Web Framework)
- الـ Real-time    : Flask-SocketIO (WebSockets للبث المباشر وWebRTC Signaling)
- قاعدة البيانات   : JSON Files (نظام خفيف لتخزين البيانات - متعدد الملفات)
- الواجهة الأمامية : HTML5, CSS3 (Glassmorphism Design), Vanilla JavaScript
- بوابة الدفع      : NOWPayments API (عملات رقمية) + Vodafone Cash (يدوي)
- المكتبات         : Requests, Secrets, Hashlib, Re, Datetime

================================================================================
2. المميزات الرئيسية (Core Features) - محدّث 2026-10-18
================================================================================

أ- نظام المستخدمين المتقدم:
   - تسجيل حساب جديد وتسجيل الدخول بالجلسات (Sessions).
   - إدارة الأدوار: Admin / User.
   - تتبع عدد مرات الدخول (login_count) وآخر دخول (last_login).
   - نظام إحالة (Referral System) بكود فريد لكل مستخدم وعمولة $10 لكل إحالة مدفوعة.
   - نظام رتب المستخدمين (Rank): Pup وما يليها.

ب- نظام التوثيق KYC (Know Your Customer) *** جديد ***:
   - يُجبر كل مستخدم جديد على رفع وثيقة هوية قبل الوصول للمنصة.
   - يدعم: National ID, Driver License, Passport.
   - يُخزّن: الاسم الكامل، تاريخ الميلاد، الجنسية/الإقامة، صورتا الهوية (أمامية وخلفية).
   - حالات KYC: not_submitted / unverified / pending / verified / rejected.
   - الأدمن يستطيع مراجعة وثائق الهوية وتغيير الحالة من لوحة التحكم.
   - يمكن للأدمن تحميل ملفات الهوية مباشرة من السيرفر.

ج- نظام الاشتراكات متعددة الطبقات *** جديد ***:
   - Starter: $30/شهر | Pro: $60/شهر | VIP: $150/شهر.
   - اشتراك دائم (Permanent) بدون انتهاء للمستخدمين المميزين.
   - تتبع تاريخ انتهاء الاشتراك (expiry_date).
   - صفحة منفصلة (expired.html) للمشتركين المنتهيين.
   - تمديد الاشتراك التلقائي من لوحة تحكم الأدمن.
   - API لعرض حالة الاشتراك والأيام المتبقية.

د- المحتوى التعليمي (Course Library):
   - عرض 52 درساً تعليمياً منظماً (TOTAL_LESSONS = 52).
   - بث الفيديوهات عبر مسارات مشفرة (Streaming) لا روابط مباشرة.
   - نظام تتبع التقدم (Progress Tracking) لكل درس بالنسبة المئوية.
   - يدعم صيغ MP4 و MKV.

هـ- نظام الدفع المزدوج *** موسّع ***:
   1. NOWPayments (Crypto - تلقائي):
      - BTC, ETH, USDT (TRC20), LTC, BNB (BSC), USDC (BSC).
      - تفعيل تلقائي فور تأكيد الدفع عبر Webhooks.
   2. Vodafone Cash (يدوي):
      - يرفع المستخدم إيصال الدفع كصورة.
      - الأدمن يراجع ويوافق أو يرفض من لوحة admin_payments.
      - يُخزَّن في ملف manual_payments.json.

و- أدوات التداول (Trading Tools):
   - حاسبة SMC لإدارة المخاطر (موجودة في home.html).
   - يوميات التداول (Trading Journal): تسجيل الصفقات مع الصور.
   - غرفة البث المباشر (Live Room) بـ WebRTC + SocketIO.
   - معرض الصفقات (Gallery): wins / zones - للأدمن والمستخدمين.
   - إشارات التداول (Signals): الأدمن ينشر، المستخدمون يشاهدون.
   - الدردشة العامة (Global Chat) + دردشة البث (Live Chat).
   - الرسوم البيانية (Chart page مع TradingView integration).

ز- لوحة تحكم الأدمن الشاملة *** موسّعة ***:
   - إدارة المستخدمين (إنشاء/تعديل/حذف/تصدير/استيراد JSON).
   - مراجعة وثائق KYC والموافقة عليها.
   - إدارة المدفوعات اليدوية (Vodafone Cash).
   - نشر إشارات التداول والتحكم في البث المباشر.
   - تحميل ملفات هوية المستخدمين.
   - تعيين الاشتراكات (مؤقت/دائم) وتحديد الطبقة (Tier).
   - رفع صور لمعرض الصفقات.

3. حماية المحتوى ومكافحة القرصنة (Anti-Piracy & Security)
================================================================================
- العلامة المائية الديناميكية: اسم المستخدم + ID فوق الفيديو بحركة متصلة.
- Token-based Video Sessions: كل جلسة مشاهدة مرتبطة بـ token مشفر (SHA-256).
- منع التحميل المباشر: streaming فقط بدون روابط ملفات.
- حماية الواجهة (protection.js): تعطيل زر الماوس الأيمن، F12، Ctrl+U، Ctrl+S.
- نظام KYC: كل مستخدم موثق بهويته الحقيقية قبل الوصول.
- تتبع الجلسات (active_sessions): منع الوصول بدون token صالح.
- Subscription Expiry Guard: المستخدمون المنتهية اشتراكاتهم يُحوَّلون لـ expired.html.

4. هيكل ملفات البيانات (JSON Data Files)
================================================================================
- users.json           : بيانات المستخدمين الكاملة (مع kyc_data, expiry_date, tier)
- messages.json        : رسائل الأدمن العامة
- journal.json         : يوميات التداول لكل المستخدمين
- gallery.json         : صور المعرض (wins/zones)
- live.json            : إعدادات البث المباشر (url, is_live, next_session)
- live_chat.json       : دردشة البث المباشر (آخر 200 رسالة)
- global_chat.json     : الدردشة العامة للمنصة (آخر 200 رسالة)
- signals.json         : إشارات التداول المنشورة من الأدمن
- manual_payments.json : طلبات الدفع اليدوي (Vodafone Cash) المعلقة

6. الـ API Endpoints الرئيسية
================================================================================
Auth & Users:
  POST   /api/register                  تسجيل مستخدم جديد
  POST   /api/login                     تسجيل الدخول
  GET    /api/users                     قائمة المستخدمين (Admin)
  POST   /api/users                     إنشاء مستخدم (Admin)
  PUT    /api/users/<id>                تعديل مستخدم
  DELETE /api/users/<id>                حذف مستخدم
  GET    /api/users/export              تصدير users.json
  POST   /api/users/import              استيراد users.json

KYC:
  POST   /api/kyc/submit                        رفع وثائق الهوية
  POST   /api/admin/users/<id>/kyc-status       تغيير حالة KYC
  POST   /api/admin/users/<id>/toggle-kyc       تبديل verified/unverified
  GET    /api/admin/kyc/download/<id>/<side>    تحميل ملف الهوية

Subscription & Payment:
  GET    /api/subscription-status       حالة الاشتراك + الأيام المتبقية
  POST   /create-crypto-payment         إنشاء طلب دفع NOWPayments
  GET    /check-payment/<id>            التحقق من حالة الدفع
  POST   /nowpayments-webhook           Webhook تلقائي من NOWPayments
  POST   /api/manual-payment            رفع إيصال Vodafone Cash
  POST   /api/admin/payments/approve/<id>  قبول دفع يدوي
  POST   /api/admin/payments/reject/<id>   رفض دفع يدوي
  POST   /api/confirm-payment           تأكيد دفع يدوي (للتطوير)

Content & Progress:
  GET    /api/progress                  نسبة إكمال الكورس
  POST   /api/progress/<lesson_num>     تحديد درس كمكتمل
  DELETE /api/progress/<lesson_num>     إلغاء إكمال درس
  GET    /stream-video/<num>            بث الفيديو (token-protected)

Trading Tools:
  GET/POST   /api/journal               يوميات التداول
  DELETE     /api/journal/<id>          حذف صفقة
  GET/POST   /api/signals               إشارات التداول
  PUT/DELETE /api/signals/<id>          تعديل/حذف إشارة
  GET/POST   /api/gallery               المعرض
  DELETE     /api/gallery/<id>          حذف صورة (Admin)
  GET/POST   /api/live/chat             دردشة البث المباشر
  GET/POST   /api/chat                  الدردشة العامة
  POST       /api/admin/live            إعدادات البث المباشر
  POST       /api/admin/gallery         رفع صور المعرض (Admin)
  GET/POST   /api/messages              رسائل الأدمن العامة
  GET        /api/referral              بيانات الإحالة والعمولات

WebRTC SocketIO Events:
  join_broadcast / offer / answer / ice_candidate / disconnect

7. كيفية الإدارة والتشغيل
================================================================================
- للتشغيل المحلي    : python app.py  -->  http://localhost:5000
- للنشر السحابي     : Render.com أو استخدام cloud.bat
- تفعيل حساب يدوياً : تغيير "has_paid": true في users.json
- KYC يدوي           : تغيير "kyc_status": "verified" في users.json
- مراقبة Webhooks    : متابعة Console الـ Flask
- تغيير سعر الكورس  : تعديل COURSE_PRICE_USD و price_mapping في app.py
